# Python Practice

A collection of Python practice scripts covering core topics.

## Files

| File | Topic |
|------|-------|
| `math_module.py` | Python `math` module — sqrt, factorial, trig, log, etc. |
| `dictionary.py` | Dictionary operations — create, access, update, delete, iterate |
| `student_records.py` | Lists of dictionaries — CRUD operations, sorting |
| `function.py` | Functions — greet, vowel counter, even/odd, factorial |
| `file_handling.py` | File I/O — read, readline, readlines, write, append modes |
| `products_assignment.py` | File I/O — read/write/append/r+ modes with product data |
